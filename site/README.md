# VetNexo marketing site + demo

Static HTML/CSS/JavaScript. No build step is required. Open `index.html` locally or deploy the `site/` directory to Cloudflare Pages. The interactive demo at `demo.html` uses fictional records and local browser-only interactions; it is not connected to the PHP application or a database.

Before public launch, replace the reserved `hello@vetnexo.example` mailto address with a verified business contact route, verify all product capability statements, and review the provisional VetNexo name for trademark/domain availability.
