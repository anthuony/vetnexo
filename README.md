# VetNexo launch package

- `site/` — English marketing landing page with pricing and a separate interactive, fictional-data demo. This is the portion designed for GitHub + Cloudflare Pages.
- `app/` — rebranded PHP source prototype. Original SQL dumps containing records, private backups, payment proofs, uploads and prior audit documents were excluded.
- `DEPLOYMENT.md` — deployment steps and readiness caveats.

Important: the website demo is front-end-only. The PHP application is not production-certified and must be hosted separately from Cloudflare Pages. Do not enter real clinic or patient data before a full security/privacy review.


## Editorial refresh
The public landing page uses an ivory, forest-green and terracotta art direction with editorial serif headings and a warm photography section. The public site is a static demo; its contact form prepares an email locally and does not transmit data. Replace the placeholder contact destination before launch.
